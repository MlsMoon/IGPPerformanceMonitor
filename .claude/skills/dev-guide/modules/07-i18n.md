# 07 · Internationalization

## Key files

- `src/i18n/__init__.py` — `tr(key, *args)`, locale detect (`IGP_LANG` override)
- `src/i18n/en.py` — English `TRANSLATIONS`
- `src/i18n/zh_CN.py` — Chinese `TRANSLATIONS`

## Responsibilities

Every UI string goes through `tr(key)`. Locale is auto-detected; `IGP_LANG` overrides.

## Pitfalls

- **No hardcoded UI strings** (the overlay once shipped Chinese literals in English locale).
- **Add keys to both `en` and `zh_CN`.** Otherwise the other locale shows the key name. `test_i18n` asserts identical key sets.
- **New UI modules must `from src.i18n import tr`.** Missing import crashed the overlay every 250ms (`NameError`).
- `tr(key, *args)` uses `str.format` (e.g. `tr("status_capturing", count, elapsed)`).

## Checklist

- [ ] New copy → `tr(key)` + both locale files
- [ ] New UI module → import `tr` at the top
- [ ] Wording change → both locales
