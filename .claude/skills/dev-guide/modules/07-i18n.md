# 07 · Internationalization

## Key files

- `src/i18n/__init__.py` — `tr(key, *args)`, locale detect (`IGP_LANG` → config `locale` → OS `zh*` → `en`), catalogs loaded from JSON
- `src/i18n/locales/<locale>.json` — one file per UI locale (`native_name` + `strings`). Adding a locale is dropping a file here
- `src/ui/dialogs/language_dialog.py` — first-run picker (`bilingual()`, not `tr()`)

## Responsibilities

Every UI string goes through `tr(key)`. Copy is **not** hardcoded in Python. UI locales are whatever JSON files exist under `locales/` (`en` / `zh_CN` today; ja / zh-TW stay docs-only until they have a catalog).

## Pitfalls

- **No hardcoded UI strings** (the overlay once shipped Chinese literals in English locale). Do not put user-facing copy in `.py` files. The first-run dialog is the exception to `tr()` only: it joins `language_picker_*` from every catalog with `bilingual()` so it does not pick a locale before the user has.
- **Add keys to every `locales/*.json`.** Otherwise the other locale shows the key name. `test_i18n` asserts identical key sets across all catalogs.
- **New UI modules must `from src.i18n import tr`.** Missing import crashed the overlay every 250ms (`NameError`).
- `tr(key, *args)` uses `str.format` (e.g. `tr("status_capturing", count, elapsed)`).
- **Detect order:** `IGP_LANG` → saved `locale` in `app_config` → OS `zh*` → `en`. Persist the in-app choice as config `locale`. Switching from Settings → Language calls `set_locale` and replaces `MainWindow` (see `01-entry.md`). Do not UAC-relaunch for a language change.
- **Do not let the picker quit the app.** `LanguageDialog` must keep `WA_QuitOnClose` off. Closing it on first run used to be `lastWindowClosed` and the main window never showed.
- **Language submenu lists `native_name` from each JSON** as exclusive checkable actions. Keep both current catalogs so first-run and later switches have a real choice.
- **Frozen EXE:** `Scripts/build.bat` must `--add-data src\i18n\locales;src/i18n/locales`. Lookup is `Path(__file__).parent / "locales"` then `resource_root()/src/i18n/locales`.

## Checklist

- [ ] New copy → key in **every** `src/i18n/locales/*.json` + `tr(key)` in code
- [ ] New UI module → import `tr` at the top
- [ ] Wording change → every locale JSON, not a Python dict
- [ ] New locale → new `locales/<code>.json` with the same keys + `native_name`; no Python list to update
- [ ] Locale detect / first-run / live switch → `IGP_LANG` still wins; `-t` never pops the picker
