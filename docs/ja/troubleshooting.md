## 管理者 / 「アクセスが拒否されました」

PresentMon には ETW が必要です。昇格に失敗したとき:

- EXE を右クリック → **管理者として実行**
- またはアカウントを **Performance Log Users** に入れる（コンピュータの管理 → ローカル ユーザーとグループ → グループ）。その後サインアウトして再サインイン
- グループポリシーやウイルス対策が `ShellExecuteW("runas")` を止めることがあります。先に昇格済みのコマンドプロンプトから実行してください

パッケージ EXE は `requireAdministrator` を宣言しています。Python 入口と `Scripts\run_dev.bat` は UAC で再起動します。

## フレームが 1 枚もない

停止時の警告は、PresentMon は動いたが present が解析できなかったという意味です。

- プロセス名は実際に提示している側です（`game.exe`。ストアのランチャーではない）
- アプリが **描画中** である必要があります。最小化した Unity エディタやサービスはフレームを出しません
- ゲーム起動後に **プロセス一覧を更新** を押す
- 排他フルスクリーンで空のままなら、ボーダレスウィンドウを試す
- ヘッドレス: `temp\igp_debug.log` の PresentMon 標準エラーを読む

## GPU / VRAM / 電力 / 温度が空

これらの系列には NVIDIA バックエンド（NVML、または `nvidia-smi` を包む GPUtil）が必要です。

- 新しい Game Ready / Studio ドライバを入れる
- AMD / Intel GPU でも PresentMon から FPS とフレームタイムは取れます
- GPU バックエンドがないとこれらのチャートは最初から隠れます。ドライバ導入後は 表示 → チャート で出してください
- プロセス別 GPU が **短時間、合計 GPU を超える** ことがあります。NVIDIA の API が 2 系統あるためで、チャートのバグではありません

空のセルは欠測（`None`）であり、ゼロではありません。

## オーバーレイが出ない / 違うウィンドウに付く

- キャプチャ中である必要があります。停止すると隠れます
- **F9** でまとめて消している可能性があります
- 追跡対象は **最も大きい** 可視・タイトル付きウィンドウです。小さな最前面ツール窓は無視されます
- 複数ウィンドウのアプリ（Unity エディタ、ブラウザ）では、いちばん大きいパネルに付きます
- 対象を最小化するとオーバーレイは隠れ、復元で戻ります

## オーバーレイをクリックできない

**設定 → クリックスルー** はマウスをゲームへ通します。その間オーバーレイの右クリックは無効です。設定メニューでクリックスルーを切るか、**F9** で隠してください。

## 自己更新しない / 「開発モード」

ヘルプ → 更新を確認 は **凍結済み EXE** だけで動きます。`python -m src.main` は必ず開発モードと出ます。

パッケージ版の確認失敗: ネットワーク、GitHub 障害、または `github.com` を止める社内プロキシ。ダウンロードには通常のブラウザ User-Agent が必要です（アプリは既に付けています）。

ロールバックには、以前の更新で残した旧版が必要です。初回インストールには戻す先がありません。

## UI 言語が違う

**設定 → 言語** で英語と簡体字中国語を切り替えます。プロセスの再起動は不要です。次回起動では `IGP_LANG` が優先されます。

```bat
set IGP_LANG=en
set IGP_LANG=zh_CN
```

未保存のときは、Windows ロケールが `zh` で始まると簡体字中国語になります。繁体字 Windows でも UI は `zh_CN` です。`docs/zh-TW/` は文書だけです。

## チャートが消えた

表示状態は保存されます。**表示 → チャート** または **Ctrl+J** で再チェックしてください。1 枚を最大化すると他は一時的に隠れます。復元すれば戻ります。

## ウィンドウが狭い / 名前が切れる

長い GPU 名とプロセス名は、ウィンドウをおよそ 1000×680 に保つため **省略表示** します。チップやリスト行にマウスを置くと全文が出ます。

## 負荷が高い / キャプチャがうるさい

GUI でマシン全体を監視しないでください。リストは短く。`--all-processes` は短いヘッドレス専用です。

上限なし FPS のゲームは生 FPS が飛びます。画面の EMA は見た目用です。ひっかかりはフレームタイムか 1% Low を見てください。

## ダークモードなのにタイトルバーが白い

現行ビルドでは修正済みです。アプリが DWM タイトルバーを塗り、常に最前面のあと再適用します（そのフラグは HWND を作り直します）。まだ白い帯が見えるなら古いビルドです。GitHub Releases から更新してください。

## 非管理者のエージェントからヘッドレスしたらファイルが無い

`python -m src.main --headless` は UAC で再起動します。昇格後のプロセスは元のコンソールを継がないため、出力が消えることがあります。`Scripts\capture_debug.bat` を使ってください。自分で昇格し、`temp\` にも書きます。

## まだ解決しない

1. ヘルプ → バージョン情報 — バージョンとビルド（`yyyyMMdd-HHmmss-gitsha`）を控える
2. `--debug` で再現し、`temp\igp_debug.log` を付ける
3. [GitHub](https://github.com/MlsMoon/IGPPerformanceMonitor/issues) で issue を開く

セキュリティ報告は公開 issue にしないでください。[SECURITY.md](../../SECURITY.md) を見てください。
